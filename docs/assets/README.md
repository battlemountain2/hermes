# Hermes and Iris design references

These JPEGs preserve visual explorations already present in the working tree. They are reference
art, not application screenshots, production icon assets, vector sources or a release announcement.
Embedded mockup dates, dimensions and placeholder credits are illustrative, not project metadata.

## Reference set

- `hermes-brand-identity.jpg`: identity sheet with icon, medallion and wordmark studies.
- `hermes-icon.jpg`: standalone Hermes icon study.
- `hermes-monomarks.jpg`: reduced-symbol explorations.
- `hermes-profile-silhouettes.jpg`: profile and silhouette variations.
- `greek-medallions-palettes.jpg`: medallion and palette exploration.
- `hermes-iris-flat-vectors.jpg`: raster reference depicting flat-symbol concepts; not editable vectors.
- `hermes-iris-minted-medallions.jpg`: paired minted-medallion concepts.
- `hermes-iris-definitive-pair.jpg`: paired bronze Hermes and olive Iris concept sheet; the filename
  does not establish a production-asset or release decision.
- `iris-simplified-olive.jpg`: simplified olive Iris reference.

The `data/themes/attic-olive.toml` and `data/themes/corinthian-bronze.toml` palette files are preserved
alongside these references. They are not registered in Hermes's built-in theme list in this snapshot.
No new icon is installed, launcher changed, or live user theme switched by this backup.

Interface action icons continue to follow the repository's Lucide and semantic-color rules.
Hermes and [Iris](https://github.com/battlemountain2/iris) keep separate repositories and technical
handoffs; shared visual references do not imply attachment, email or shared-library integration.
